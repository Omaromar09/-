# موقع الفارانده ورك سبيس وكافيه | El Veranda Workspace & Café 🌿☕

موقع ويب احترافي ومتجاوب لمساحة عمل وكافيه **الفارانده (El Veranda)** في شارع شبرا، شارع المقسي (أمام مدرسة نور العلم للغات).

---

## 📂 هيكل صفحات الموقع (Multi-Page Architecture)

1. **الصفحة الرئيسية (`index.html`):**
   - سيرة الفارانده وقصة المكان الواقعية.
   - نظام الأسعار الصريح: **الساعة بـ 15 ج.م** • **أكتر من 3 ساعات = 60 ج.م لليوم كله**.
   - استكشاف المساحات والأركان (التراس المفتوح، غرف المذاكرة، الركن البدوي، صالة المشاريع، ركن الفن).
   - بطاقة تشويقية لكافيه وحلويات الفارانده مع زر مباشر لفتح صفحة المنيو المنفصلة.
   - المعرض الحي لجميع الصور الحقيقية الـ 11.
   - العنوان، أقرب محطة مترو (مسرة وروض الفرج)، والخريطة التفاعلية.
   - روابط السوشيال ميديا وواتساب المباشر (`01024824760`).

2. **صفحة المنيو والكافيه المنفصلة (`menu.html`):**
   - صفحة خاصة وقائمة مستقلة بالكامل للمشروبات والحلويات.
   - محرك بحث حي وتصفية حسب الفئات (ساخن، بارد مثلج، حلويات وسناكس).
   - الأصناف كاملة بأسعارها:
     - شاي فاخر: **10 ج.م**
     - قهوة تركي مخصوص: **15 ج.م**
     - ماونتن كيك الشهير (Mountain Cake): **50 ج.م**
     - هوت شوكليت بلجيكي: **35 ج.م**
     - سبانيش لاتيه، آيس كوفي، سموذي، مولتن كيك، وغيرها الكثير.
   - حاسبة إجمالي الطلب الذكية مع زر إرسال الطلب فورياً عبر واتساب (`01024824760`).
   - زر سريع للرجوع لصفحة مساحة العمل الرئيسية.

---

## 🚀 ملفات التشغيل السريع على سطح المكتب
- **`افتح موقع الفارانده.bat`**: يفتح الصفحة الرئيسية لمساحة العمل.
- **`افتح منيو الفارانده.bat`**: يفتح صفحة المنيو والحلويات المنفصلة مباشرة.
